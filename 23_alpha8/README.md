# Taktera Studio · Alpha.8

Откройте `index.html` в браузере. Доступны восемь сценариев: Button, Text field, Badge, Alert, Tabs, KPI card, Data table, Skeleton; шесть продуктов и две темы. Изменяйте состояния, плотность, RU/EN и сравнивайте вариант A с альтернативным вариантом B.

**Область применения:** автономная интерактивная документация и демонстрационные HTML-реализации. Скопированные сниппеты описывают семантическую структуру; классы `tk-*` являются примерами, а не публичным API Web Core. Не используйте эти сниппеты как готовую производственную библиотеку.

**Проверка:** модульные браузерные проверки в Chromium и сканирование синтаксиса JavaScript. Требуются внешние тесты NVDA/VoiceOver, Firefox/Safari и реальное приложение; никаких автоматических утверждений об успешном WCAG-аудите.

**Сравнение:** предпросмотры A/B показывают два варианта текущего компонента в противоположных темах. Это не сравнительный инструмент git-версий и не автоматическая проверка пиксельных регрессий.
