<h2>7. Иконки — Lucide</h2>
<div class="legacy"><b>Существующее правило из исходного дизайн-кода:</b> UI использует <b>lucide-react</b>, толщина линии — <b>1.5 px</b>, размеры — 16 / 20 / 24 / 32 px, цвет наследуется от текста.</div>
<div class="proposal"><b>Nexus v2.1 уточняет систему:</b> Lucide становится единственной канонической библиотекой интерфейсных пиктограмм. Локальные SVG допускаются только для уникальных доменных понятий, которых нет в Lucide, и должны визуально соответствовать геометрии Lucide. Каталог: <a href="https://lucide.dev/icons/" target="_blank" rel="noreferrer">lucide.dev/icons</a>.</div>

<h3>7.1. Базовые правила</h3>
<table><tr><th>Параметр</th><th>Правило</th><th>Примечание</th></tr>
<tr><td>Stroke</td><td><code>1.5</code></td><td>Фирменное правило Taktera; Lucide по умолчанию показывает 2 px, в продукте переопределяем на 1.5.</td></tr>
<tr><td>Размеры</td><td><code>16 / 20 / 24 / 32</code></td><td>20 px — default UI, 16 px — compact, 24 px — major action, 32 px — illustrative.</td></tr>
<tr><td>Цвет</td><td><code>currentColor</code></td><td>Иконка наследует semantic token текста/состояния.</td></tr>
<tr><td>Fill</td><td>нет</td><td>Не использовать filled-версии, градиенты, glow, тени или разноцветные stroke.</td></tr>
<tr><td>Геометрия</td><td>native Lucide 24×24</td><td>Не масштабировать path вручную; менять только <code>size</code>.</td></tr>
<tr><td>Hit area</td><td>≥ 32×32 px</td><td>Для touch предпочтительно 40×40 px; сама пиктограмма остаётся 16–24 px.</td></tr>
<tr><td>Accessibility</td><td>обязательна</td><td>Decorative: <code>aria-hidden</code>; icon-only button: доступное имя/label.</td></tr></table>
