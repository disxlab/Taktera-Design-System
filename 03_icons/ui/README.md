# UI icons / Taktera 3.3 (assets unchanged from v3.2)
Lucide / lucide-react, strokeWidth 1.5, sizes 16 / 20 / 24 / 32, currentColor.
Keep the supplied semantic registry. Context icons (Stethoscope, Sparkles, Waves, Dumbbell, Plane) are interface pictograms, never product logos.
Icon-only buttons require an accessible name. Minimum hit area 32px for compact desktop; use 44px for touch.
Status = text + icon + semantic color, never color alone. Dark theme uses semantic colors distinct from brand accents.
No custom decorative SVG set is carried over. Existing clinical domain icons may remain only where Lucide has no semantic equivalent.
