# Board migration — Alpha.8 → Alpha.9

Проверяйте данные в `21_alpha6/dashboard.html`. Новые задачи DS-028–DS-030 добавляются к сохранённой локальной доске по ID, не перезаписывая старые статусы. Изменения в существующих задачах, сделанные пользователем, имеют приоритет. **Исходное значение статуса DS-021, DS-023–DS-025 в обновлённой поставке не перезаписывает локальную копию пользователя.**

Перед заменой пакета: экспорт JSON; после открытия новой версии проверьте DS-021–DS-025 и при желании вручную приведите статусы к поставленной Alpha.9.

Если сохранённый файл импортируется вручную, импорт целиком заменяет текущие задачи; перед ним всегда выполняйте экспорт.
