# Taktera Iconography · Alpha.9 (proposal)

## Правила
- В интерфейсе использовать единый набор **Lucide**, согласованные версии SVG и лицензии; не подменять продуктовые логотипы UI-пиктограммами.
- Размеры: 16 / 20 / 24 px; размер 16 — плотные таблицы, 20 — типовые кнопки, 24 — навигационные акценты. Размер должен соответствовать доступной области касания.
- Stroke: 1.75–2 px для 20–24 px, оптическую толщину для 16 px проверять визуально. Не смешивать filled и outline без функции.
- Цвет иконки наследуется от текста; статус успех/ошибка задаётся семантическим токеном, **не** цветом продукта.
- Значимые действия снабжать доступным именем. Декоративные SVG — `aria-hidden=true`, не озвучивать повторно рядом с подписью.
- Проверять контраст, фокус, hover/disabled, zoom 200% и RTL только при реальной потребности.

## Продуктовые иконки
- Утверждённые оригиналы: `03_icons/app/`.
- Варианты A/B: `14_brand_extensions/icons_proposed/` — **кандидаты**, не production assets.
- Критерий утверждения: узнаваемость рядом с другими продуктами, 16/24/32/48/128/256 px, Windows taskbar, macOS Dock, обе темы; решение владельца бренда.
- Не заменять мастер-знак и lockup без отдельного согласования.
