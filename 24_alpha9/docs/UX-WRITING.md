# Taktera UX Writing · RU/EN · предложение Alpha.9

## Голос
Спокойный, точный, профессиональный. Без обещаний, не подтверждённых фактическим результатом.

## Основные принципы
1. Название действия = результат: «Сохранить запись», не «Готово».
2. Ошибка = что произошло + как исправить: «Не удалось сохранить запись. Проверьте подключение и повторите попытку».
3. Не утверждать успешное действие до подтверждения сервера.
4. Для опасных действий — называть объект и последствия: «Удалить запись без возможности восстановления?» (только если действительно необратимо).
5. Для пустого состояния: описать причину/состояние и дать ближайшее действие.
6. Даты, валюты, адреса и медицинские термины проверять в домене; примеры — демонстрационные, не юридические тексты.

| Контекст | RU | EN |
|---|---|---|
| Сохранение | Сохранить изменения | Save changes |
| Пустая таблица | Записей пока нет | No records yet |
| Ошибка сети | Не удалось загрузить данные. Повторите попытку. | Could not load data. Try again. |
| Удаление | Удалить запись? | Delete this record? |
| Подтверждение | Изменения сохранены | Changes saved |
| Идёт действие | Сохранение… | Saving… |

Тексты — редакционные образцы; продуктовая локализация требует терминологического ревью и тестов контекста.
