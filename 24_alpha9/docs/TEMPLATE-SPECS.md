# Templates · Alpha.9

Шаблоны — рабочие HTML/SVG-образцы, **не юридически проверенные документы**.

| Пример | Формат | Применение |
|---|---|---|
| Business proposal | HTML / print-to-PDF | Коммерческое предложение, вводная информация и условия |
| Business letter | HTML / print-to-PDF | Деловое письмо с адресатом и реквизитами |
| Email announcement | HTML | Информирование клиентов, адаптация к email-клиентам необходима |
| Presentation cover | SVG 16:9 | Обложка презентаций и материалов |

Использовать заглушки для реквизитов, фамилий, цен, сроков и условий; не отправлять примеры клиентам без заполнения и проверки. Применение в реальных email-клиентах и печати ещё не сертифицировано.
