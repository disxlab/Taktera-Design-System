# Taktera v3.3 · переносимая инженерная сборка

Все скрипты разрешают пути относительно директории файла, не требуют абсолютных путей компьютера автора.

1. `python 09_source/generate_tokens.py` — исходный `04_tokens/taktera.tokens.json` → CSS, DTCG 2025.10, JSON-отчёт контраста. Только stdlib.
2. `python 09_source/generate_tokens.py --check` — проверить, что сгенерированные значения актуальны.
3. `python 09_source/rebuild_assets.py --output ../Taktera_v3.3_reexports` — переработать существующие SVG в соответствующие PNG и ICO (требует CairoSVG, Pillow). Создаёт **отдельный** каталог и не изменяет мастера.
4. `python 09_source/release.py` — структурный контроль, проверка цвета, ссылок, шрифтов и PDF, SHA-256 манифест и финальный ZIP. Требует Pillow, fontTools, pypdf.

В `legacy_v3.2` сохранены исходные скрипты и отчёты из предыдущей версии. Они исторические, содержат специфичные для прежнего компьютера настройки и не являются частью новой сборочной цепочки.

Скрипт `rebuild_assets.py` не реконструирует геометрию из референсного растра: канонические SVG зафиксированы в `02_logos`. 14-страничный брендбук остаётся версией 3.2; к нему добавлено инженерное дополнение v3.3.
