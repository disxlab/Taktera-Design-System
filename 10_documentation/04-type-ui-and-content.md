# 04. Типографика, интерфейс и тексты

Taktera · редакция 3.2 · 18 октября 2026

## Шрифты

Основной шрифт — Inter. В комплекте есть статические начертания Regular 400, SemiBold 600 и Bold 700, исходный variable TTF и OFL.txt. Для статических файлов использована оптическая ось opsz 24. Не подключайте variable и статические файлы одновременно под одним именем без явной схемы начертаний.

| Роль | Размер / интерлиньяж, px | Начертание |
| --- | --- | --- |
| Крупный заголовок | 48 / 52 | 700 |
| H1 | 30 / 36 | 700 |
| H2 | 24 / 30 | 600 |
| H3 | 18 / 24 | 600 |
| Основной текст | 14 / 21 | 400 |
| Подпись | 12 / 16 | 400 |

Логотипы используют контуры Inter Bold с фиксированными интервалами. Для таблиц, сумм и счётчиков включают tabular-nums. Для ID и кода допускается JetBrains Mono, если он уже подключён в продукте; иначе системный monospace. JetBrains Mono в комплект не включён.

## Общие параметры UI

| Параметр | Правило |
| --- | --- |
| Ритм | Отступы кратны 4 px |
| Радиусы | 4 / 6 / 8 / 12 / 16 px |
| Движение | 150 / 250 / 400 ms; учитывать prefers-reduced-motion |
| Пиктограммы | Lucide, currentColor, линия 1.5 px |
| Размеры пиктограмм | 16 / 20 / 24 / 32 px |
| Область нажатия | Рекомендуется 44 × 44 px для touch; минимум 32 × 32 px для компактного desktop |

Рекомендуемый подход к композиции: ясная иерархия, свободные поля, минимум теней. Цвет выделяет действие и продукт, а не всю страницу. Декоративный изгиб и точка уместны на обложке; их не помещают за таблицами и формами.

## Иконки и доступные названия

Карта иконок и React registry находятся в 03_icons/ui. Контекстные Stethoscope, Sparkles, Waves, Dumbbell и Plane помогают обозначить сферу, но не заменяют фирменный знак. Кнопкам только с иконкой задают понятное доступное имя. Если изображение дублирует видимый текст, его alt оставляют пустым; самостоятельному логотипу дают название бренда или продукта.

## Рекомендации для текстов

Этот раздел задаёт редакционную рекомендацию для внедрения, а не новую визуальную концепцию. Пишите спокойно, конкретно и доброжелательно. Называйте действие и следующий шаг. Избегайте обещаний, которые продукт не выполняет, и декоративных восклицаний.

| Контекст | Пример |
| --- | --- |
| Кнопка | Сохранить запись |
| Успех | Запись сохранена |
| Ошибка | Не удалось сохранить запись. Попробуйте ещё раз. |
| Пустой список | Записей пока нет. Создайте первую запись. |
