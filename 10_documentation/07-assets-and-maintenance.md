## Имена файлов

| Шаблон имени | Пример / назначение |
| --- | --- |
| {product}-{theme}.svg | fitness-light.svg — полная композиция для светлого фона |
| {product}-mark-{theme}.svg | travel-mark-dark.svg — знак и точка для тёмного фона |
| {product}-{theme}-{size}.png | travel-dark-512.png — app icon 512 × 512 |
| {product}-{theme}.ico | clinic-light.ico — иконка Windows/favicon |
| taktera-{theme}.svg | Корпоративный логотип |
| mark-mono-{theme}.svg | Монохромный знак |

Для app icons доступны размеры 16, 24, 32, 48, 64, 128, 256, 512, 1024 px. Логотипы PNG прозрачные, app icons имеют собственную подложку. Полный машиночитаемый каталог ресурсов находится в ASSET-CATALOG.csv; контрольные суммы всех файлов — в PACKAGE-MANIFEST.json в корне.

## Обновления

В версии 3.2 закреплена красная палитра Fitness и жёлтая Travel. Редакция 3.2 добавляет русские логотипы и метки в app icons без изменения геометрии знака и палитры. При последующих изменениях обновляйте JSON/CSS, экспорты, брендбук и CHANGELOG вместе. Старый комплект храните отдельно с его номером версии.

В 09_source включены скрипты генерации, визуального экспорта, дополнения документации и проверки. Они отражают среду сборки автора и содержат локальные пути. Перед запуском на другом компьютере пути и зависимости настраиваются; сборка не является переносимой командой «в один клик». Генератор брендбука перезаписывает часть файлов, поэтому полную документацию собирают после него.
