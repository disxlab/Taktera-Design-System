## Состав

Каталоги `01_brandbook` – `10_documentation` сохраняют исходные ресурсы (за исключением технического расширения токенов, шрифтов и исправления README и файлов контроля). Каталог `11_design_system` содержит спецификации и руководство v3.3; `12_examples` — офлайн-демо. Прежние файлы отчётности и зависящие от Windows скрипты в `09_source/legacy_v3.2` сохранены как исторические материалы. Полный список и SHA-256 — `PACKAGE-MANIFEST.json`; проверки — `VALIDATION.json`.

## Команды для разработчика

```bash
python 09_source/generate_tokens.py --check
python 09_source/release.py
```

Для скрипта релиза нужны Python 3.11+, Pillow, fontTools, pypdf; графический реэкспорт из SVG (не обязателен для использования готового пакета) требует CairoSVG и Pillow. Пользовательские приложения в рамках этого пакета не изменены. Перед production rollout требуется тестирование UX и доступности на реальных экранах.

## Важные ограничения

Стандартная палитра статусов v3.3 — инженерное предложение на основе контраста, требующее интеграционного QA. Это не юридический аудит товарного знака, не печатный тиражный пакет и не готовая production библиотека React/Avalonia. Английские логотипы, русские варианты, микросимволы и брендбук PDF v3.2 остаются неизменными. Не заменяйте текущее визуальное руководство экспериментальными идеями до их утверждения.
