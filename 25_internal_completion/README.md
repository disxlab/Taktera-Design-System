# Taktera Design System — Beta Readiness 1

Внутренние задачи DS-010/011/012 закрыты на уровне исходников, генераторов и автоматизированных проверок. Работа с эталонами DS-020 продолжается.

## Что создано
- `src/formatters.mjs`: Intl API, RU/EN, даты, RUB/USD, числа/проценты, формы числа, словари интерфейса. В demo дату `YYYY-MM-DD` форматируем в UTC, чтобы не изменять день при локальной конвертации; бизнес-таймзоны должны быть определены отдельно.
- `src/tokens.canonical.json`: единый источник экспорта, содержащий базовые, семантические и утверждённые продуктовые цвета из v3.3 и расширения Alpha.6. Утверждённая часть не изменена.
- `src/build_tokens.py`: детерминированная генерация Web CSS и 12 Avalonia ResourceDictionary (Color/Brush/Double). Это ресурсы, **не подтверждённые нативной сборкой**.
- `index.html`: интерактивный демонстратор тем, локалей, типографики и плотности.
- `qa/baselines`: визуальные эталоны Chromium. Не считать их мультибраузерными эталонами.

## Проверки
```bash
python 25_internal_completion/src/build_tokens.py
node 25_internal_completion/src/test_formatters.mjs
```
Для проверки идентичности файлов: повторить генератор и сверить SHA-256 всех файлов в `generated/`.

## Важные ограничения
Словари Avalonia XML распарсены, но `dotnet build` и просмотр Windows/macOS остаются открытыми. Типографика и плотность проверены в демонстраторе, но не признаны безусловно утверждённым продуктовым стандартом. Часовые пояса и валюты в боевых процессах должны конфигурироваться приложением; локаль интерфейса не обязана определять валюту договора. Полный RTL, все страны/валюты, скринридеры и Firefox/Safari не проверены.
