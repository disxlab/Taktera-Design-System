# Taktera typography
Inter from https://github.com/google/fonts/tree/main/ofl/inter, distributed under OFL.txt.
Inter-Variable.ttf is upstream source; static Regular 400 / SemiBold 600 / Bold 700 files were instantiated at opsz 24 using fontTools.
Logo lettering uses outlined Inter Bold with fixed optical tracking. SVG masters need no installed font.
UI: Inter 400 / 600 / 700. JetBrains Mono for code and IDs remains optional and is not bundled.
